# product-photo-tools

Скрипты на Python для пакетной обработки фотографий товаров: подготовка под требования маркетплейса, порядок в папках, поиск ошибочных обложек и сортировка фотосессии по артикулу, распознанному на этикетке (OCR).

Выросли из реальной работы с фотоконтентом в рознице одежды и обуви, где тысячи фото после съёмки нужно разложить по товарам, привести к размеру площадки и проверить. Для портфолио скрипты переписаны: пути и параметры задаются при запуске, общий код вынесен в модули, опасные операции стали обратимыми, добавлены тесты и примеры на синтетических картинках.

## Что умеет

| Скрипт | Задача |
|---|---|
| `sort_by_label.py` | Раскладывает фотосессию по папкам товаров. Съёмка идёт сериями «кадры товара + этикетка». Скрипт распознаёт артикул на этикетке через Tesseract OCR и кладёт серию в папку с именем артикула. |
| `find_label_photos.py` | Находит папки, где первым (обложкой карточки) стоит фото этикетки, а не товара. Использует компьютерное зрение (OpenCV), сохраняет отчёт CSV и может перенести этикетку в конец. |
| `resize_photos.py` | Приводит все фото к размеру площадки (например, 2048×2684) с учётом ориентации кадра. Рекурсивно обходит подпапки и по умолчанию сохраняет результат в отдельную папку. |
| `tidy_folders.py` | В каждой папке товара оставляет первые N фото (или фото с заданными номерами) и нумерует их 1, 2, 3… |

## Как это устроено

**Распознавание этикетки** (`photo_tools/labels.py`). Классификация без нейросети, по признакам изображения:
- доля почти белых пикселей: этикетка — это белый фон;
- доля горизонтальных линий после детектора границ Canny и морфологического открытия: строки текста дают горизонтальную текстуру;
- соотношение сторон и контраст.

Правила проверяются от самого уверенного к менее уверенному, в отчёте видно, какое сработало. Признаки считаются на копии шириной 800 px, поэтому анализ большой папки занимает минуты.

**OCR артикула** (`photo_tools/ocr.py`). Перед распознаванием мелкий текст увеличивается, кадр переводится в чёрно-белый с автоматическим порогом (метод Оцу), затем Tesseract. Артикул ищется регулярным выражением (по умолчанию формат `KLRL421MN BLK 105`), шаблон можно задать своим через `--pattern`. Нераспознанные серии не теряются: они попадают в папки `не распознан_…`.

**Размер под площадку** (`photo_tools/resize.py`). Три режима:
- `pad` (по умолчанию) — вписать кадр целиком и дополнить белыми полями;
- `crop` — заполнить кадр, обрезав края;
- `stretch` — растянуть, как делала первая версия скрипта. Этот режим искажает пропорции, поэтому оставлен только для совместимости.

Поворот, записанный камерой в EXIF, учитывается.

**Безопасность файлов** (`photo_tools/files.py`).
- Лишние фото по умолчанию переносятся в `_лишние`, а не удаляются. Есть пробный запуск `--dry-run`.
- Нумерация 1, 2, 3… идёт в два прохода через временные имена. В первой версии файл, уже называвшийся «2.jpg», мог быть удалён при переименовании другого файла в «2.jpg».
- Фото сортируются «как в проводнике»: `DSC_9` раньше `DSC_10`.
- Пути с кириллицей читаются корректно (`cv2.imread` в Windows их не открывает).

## Быстрый старт

```bash
pip install -r requirements.txt
```

Для `sort_by_label.py` нужен [Tesseract OCR](https://github.com/tesseract-ocr/tesseract). В Windows путь к нему можно передать параметром `--tesseract "C:\Program Files\Tesseract-OCR\tesseract.exe"`.

```bash
python sort_by_label.py     examples/shoot
python find_label_photos.py examples/catalog
python resize_photos.py     examples/photos --size 2048x2684
python tidy_folders.py      examples/catalog --keep 5 --rename --dry-run
```

Пример вывода `sort_by_label.py`:

```
IMG_0003.jpg: KLRL421MN BLK 105 → KLRL421MN BLK 105/ (3 фото)
IMG_0006.jpg: KNWD118PB WHT 042 → KNWD118PB WHT 042/ (3 фото)
IMG_0009.jpg: артикул не найден → не распознан_IMG_0009/ (3 фото)
Серий: 3, артикул распознан: 2, не распознан: 1
```

Третья этикетка в примере специально смазана: так выглядит кадр не в фокусе.

Результаты сохраняются в `result/`. Скрипты, которые меняют файлы на месте (`tidy_folders.py`, `find_label_photos.py --fix`), лучше сначала запускать на копии папки. Справка по параметрам: `python <скрипт>.py --help`.

Все картинки в `examples/` синтетические, их создаёт `python examples/make_examples.py`. Артикулы выдуманы.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Тест OCR пропускается, если Tesseract не установлен.

## Ограничения

- Правила распознавания этикетки подобраны под предметную съёмку на цветном или сером фоне. Если товар снимают на чисто белом фоне, правило «почти весь кадр белый» даст ложные срабатывания, и пороги нужно подстроить. Следующий шаг — обучить простой классификатор на размеченных фото.
- OCR чувствителен к фокусу и бликам на этикетке, поэтому нераспознанные серии стоит проверять глазами.

## Стек

Python 3.10+, OpenCV, Pillow, NumPy, Tesseract OCR (pytesseract), pytest.
